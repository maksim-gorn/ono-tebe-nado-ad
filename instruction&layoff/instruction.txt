Шаг 0. Изучите концепцию проектной работы
Проект разделён на два больших блока:
общие настройки и создание базовой структуры документа,
последовательная вёрстка секций.
Базовая структура документа — это крепкий фундамент, который не позволит проекту обрушиться при первом дуновении ветра. Корректная структура помогает выполнить работу так, как она задумывалась изначально. Результат будет предсказуемым, а критичные ошибки можно заметить и исправить на первых этапах.
Ошибки, обнаруженные в конце работы, стоят дороже всего — из-за них, скорее всего, придётся многое переделывать.
Совсем без ошибок, конечно же, не получится, но чем раньше вы их обнаружите, тем лучше. Замечать ошибки проще, если двигаться по плану и периодически сверяться с ним.
Работа над проектом будет строиться по методу прогрессивного джипега, который описал Артемий Лебедев. Согласно этому методу, проект сразу создаётся полностью, дальше происходит доработка и детализация.

Такой метод помогает эффективнее распределять время и формирует стратегический взгляд на разработку. Вы подходите к проекту не как к чтению книги — последовательному процессу с неизвестным финалом, а как к созданию картины — набрасываете эскиз и композицию, и только потом углубляетесь в детали. Именно стратегический подход позволяет вовремя замечать ошибки.

1. Добавьте оверлей
В макете есть секция с фоновым декоративным изображением. Это один из случаев, когда уместно задать блоку минимальную высоту через свойство min-height. Такой подход гарантирует, что фоновое изображение будет отображаться корректно даже при небольшом количестве контента. А высота блока по-прежнему сможет увеличиваться в зависимости от содержимого.
Избегайте фиксации высоты элементов без необходимости, иначе это может привести к проблемам с адаптивностью и переполнением контента. Позвольте контенту определять высоту там, где это возможно.
Поверх секции лежит оверлей. Он-то нам и нужен! Это пустой контейнер div с абсолютным позиционированием.
Чтобы абсолютное позиционирование работало правильно, задайте родительскому блоку свойство position со значением relative.
Сверстайте оверлей так, чтобы потом применить такой же класс к любому другому элементу на странице — оверлей также встретится в карточках ниже. Уже скоро вы научитесь обходиться без таких пустых контейнеров.
Следите за свойством z-index у всех элементов внутри секции, иначе они могут спрятаться под оверлеем.

Шаг 6. Выполните детальную стилизацию секции с карточками
В этой секции основные трудности могут возникнуть при вёрстке списка карточек. Мы разберём только его. Заголовок и ссылку сверстайте самостоятельно.
Сбросьте стили элементов списка.
Задайте элементу списка, тегу <li>, ширину и минимальную высоту. А для тега <a> и контейнера карточки <article> укажите высоту 100%. В дальнейшем эта высота поможет расположить контент карточки согласно макету.
Поработаем с фоновыми изображениями. Изображения должны заполнять всю площадь карточки (background-size: cover). Проконтролируйте, чтобы позиционирование изображения было в центре (background-position: center). Убедитесь, что классы для фона не дублируют общие правила оформления карточек.
Установите взаимное расположение элементов с использованием флексбокса. Между карточками есть пустое пространство — его можно задать свойством gap. Контент внутри карточки лучше расположить с помощью флексбокса, изменив направление основной оси — используйте свойство flex-direction.
Обеспечьте корректную работу секции с карточками при переполнении: если добавляется четвёртая карточка, она должна переноситься на новую строку. Контролируйте, что при переносе горизонтальный разрыв между карточками сохраняется.
В карточке сбросьте подчёркивание, полученное от ссылки.
Добавьте оверлей в каждый <article> карточки. Это тот самый оверлей, который вы уже создали для входного экрана. Чтобы оверлей правильно позиционировался относительно самой карточки, для <article> нужно указать свойство position со значением relative. Следите за z-index, ведь ваш оверлей спозиционирован абсолютно.
Уроки, которые помогут
Уроки «Преобразование во флекс-контейнер» и «Направление внутри флекс-контейнера» помогут сверстать сетку карточек, а уроки «Выравнивание по основной оси» и «Настройка отступов с помощью gap» — настроить отступы между карточками.
Ориентируйтесь на предыдущие ссылки: z-index, фон и относительное позиционирование.
Рекомендуемые имена классов
lots — вся секция;
lots__heading — заголовок секции;
lots__card-list — список карточек;
lots__card-list-item — пункт списка карточек;
card-link — ссылка, обрамляющая карточку;
card — карточка;
card_type_film, card_type_book и card_type_picture — классы для фона каждой из карточек;
overlay — такой класс уже есть в вашем коде;
card__title — заголовок карточки;
card__text — текст карточки;
lots__look-more-link — ссылка «Посмотреть больше».
Шаг 7. Реализуйте секцию «Об аукционе»
Используйте гриды, чтобы задать размер колонок. Левая колонка должна быть равна ширине карточки из предыдущей секции, а правая — занимать всё оставшееся пространство.
Добавьте дополнительный контейнер для логотипа, чтобы задать ему фон. Можно использовать тег <div>. Установите для него фиксированные ширину и высоту и сделайте его круглым и чёрным.
Внутри этого контейнера разместите белый логотип. Чтобы логотип встал по центру, используйте флексбокс на родительском контейнере с выравниванием по центру вдоль основной и поперечной осей. Контейнер разместите по горизонтальному центру левой колонки.
Добавьте заголовок секции и расставьте его отступы.
Сгруппируйте два параграфа в обёртку div. Воспользуйтесь свойством gap для создания гибкого отступа между параграфами. Важно обеспечить автоматическую адаптацию отступа при изменении количества параграфов.
Уроки, которые помогут
Ориентируйтесь на упомянутые уроки о флексбоксе, настройке отступов, гридах, столбцах и строках грид-контейнера и выравнивании внутри грид-контейнера.
Рекомендуемые имена классов
about — вся секция;
about__column — класс для колонок;
about__logo — контейнер с логотипом;
about__logo-image — изображение логотипа;
about__title — заголовок секции;
about__text — блок для текстов (параграфов) секции.
Вы можете использовать и другие классы, если они вам понадобятся.
Шаг 8. Сверстайте подвал сайта
Расположите элементы с помощью гридов.
Стилизуйте адрес. Вы уже верстали левую колонку, переиспользуйте блок <address>. Учтите, что здесь не такое выравнивание внутри контейнера, как в шапке.
Для правой и центральной колонки создайте списки ссылок:
Центральная колонка — это список ссылок с текстом, выровненным по центру.
Правая колонка — список со ссылками-изображениями.
Уроки, которые помогут
Ориентируйтесь на предыдущие ссылки: семантика, гриды, столбцы и строки грид-контейнера, флексбокс и выравнивание по его осям.
Рекомендуемые имена классов
footer — подвал;
address — такой класс уже есть в вашей вёрстке, все вложенные элементы аналогичны;
footer__menu — блок навигации по списку ссылок. Рекомендуем вложить список в тег <nav> с этим классом;
footer__menu-list — список пунктов меню;
footer__menu-list-item — пункт списка меню;
footer__menu-link — каждая ссылка в пункте списка;
footer__menu-link_active — выбранная ссылка меню (без подчёркивания);
footer__social-list — список ссылок на социальные сети. Можно не добавлять тег <nav>, потому что ссылки ведут на внешние ресурсы;
footer__social-list-item — пункт списка ссылок на социальные сети;
footer__social-link — ссылка на социальные сети;
footer__social-icon — иконка социальной сети.
